# v2.0 驗證記錄

日期：2026-09-09；Windows 11 x64；Python 3.13.14。

- 13 項自動化測試透過：下載連結/畫質/字幕，以及錄製引數、失敗保留、成功釋出。
- 720p（1280×720）和 1080p（1920×1080）實錄 MP4，FFmpeg 完整解碼透過。
- 無音訊、系統聲音、系統聲音+麥克風短時錄製透過；帶暫停續錄的 MP4 合併透過。
- 系統靜音場景透過；播放測試音後，迴環錄製音軌包含非零訊號。
- 介面操作驗證：取消倒計時、開始、暫停、繼續、停止儲存、浮動控制欄透過。
- 獨立 EXE 的三個頁面可啟動，PyAudioWPatch 可列舉 21 個音訊裝置；下載 worker 啟動透過。
- 程式碼差異格式和依賴一致性檢查透過。

限制：未做數小時連續錄製壓力測試，未驗證其他電腦/顯示卡/音效卡組合、熱插拔裝置或多顯示器縮放組合；未重新實測外部網站下載。
